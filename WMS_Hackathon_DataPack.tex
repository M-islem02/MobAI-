\section{Lisez-moi (Instructions)}

\begin{itemize}
    \item Chaque onglet correspond à un modèle de fichier CSV.
    \item \textbf{Ligne 1} = en-têtes de colonnes. \textbf{Ligne 2} = types. \textbf{Ligne 3} = obligatoire (O/N). \textbf{Ligne 4+} = données.
    \item Les équipes peuvent ajouter des colonnes, mais ne doivent \textbf{PAS} renommer ni supprimer les colonnes de base.
    \item Les identifiants (ID) peuvent être des entiers ou des UUID; ils doivent correspondre entre les tables (clés étrangères).
    \item Si vous n'avez pas de commandes d'achat ouvertes ou de délais, vous pouvez laisser les tables optionnelles vides et utiliser des valeurs par défaut.
    \item Utilisez les formats ISO : date = \texttt{YYYY-MM-DD}, date/heure = \texttt{YYYY-MM-DD HH:MM:SS}.
\end{itemize}
